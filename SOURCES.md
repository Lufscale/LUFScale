# LUFScale 2.2.3 source code

The corrected macOS and Windows application sources and builders are stored separately in `sources/macos` and `sources/windows`. Build instructions, licences and notices are provided in each directory. The twelve PDF guides per platform are included in the release build kits and verified before packaging. The generator sources are retained for future documentation updates.

The macOS source-compliance release archive includes the LUFScale build kit, archived third-party sources from the tested community distributions, and separate Apple Silicon and Intel build manifests. The ready-to-use community ZIPs also include their corresponding third-party sources and notices.

The Windows source ZIP is a LUFScale build kit. It is not represented as a complete corresponding-source archive for every linked component of its prebuilt FFmpeg binary. Consult its third-party notices and FFmpeg build records. The existing Windows dependency-source limitation has not been resolved by this release.

The application code is licensed under GPL-3.0-or-later. Dependencies retain their own licences. Historical release records remain in Git history and in the existing GitHub Releases; do not replace or delete previously published assets.
