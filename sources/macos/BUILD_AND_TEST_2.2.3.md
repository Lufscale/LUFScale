# Build and test LUFScale 2.2.3 for macOS

1. Extract the entire ZIP into a new local folder. Do not overlay an old build directory.
2. Open `Create_Community_Distribution_macOS.command` from the extracted folder. An Internet connection is required to prepare the pinned build tools and dependencies.
3. Wait for completion. Full build logs are stored in `build-logs`.
4. Test the outputs in `dist`. Confirm version 2.2.3 and open Help after switching application languages. All twelve approved PDF guides are included; their content and layout are retained with version references updated to 2.2.3.
5. Run the native checks listed in `VALIDATION_2.2.3.md`.

## Files to return after testing

Build this same source kit on each target architecture:

- Apple Silicon: `dist/LUFScale-2.2.3-macOS-arm64-community.zip` and its `.sha256` file.
- Intel: `dist/LUFScale-2.2.3-macOS-x86_64-community.zip` and its `.sha256` file.

The `dist/LUFScale.app` bundle is available for local testing. The community ZIP also carries the build records, licenses and corresponding-source files generated by the native builder.

If construction fails, return the relevant `build-logs` files. No GitHub or website upload is needed during testing.
