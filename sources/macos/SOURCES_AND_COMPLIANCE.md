# LUFScale 2.1.12 — macOS source and compliance kit

This single kit accompanies the ready-to-use Apple Silicon (`arm64`) and Mac
Intel (`x86_64`) distributions. It is not required to install or run LUFScale.

It contains:

- the LUFScale source code and macOS build scripts;
- the exact FFmpeg, LAME, libogg, libvorbis and Opus source archives in
  `corresponding-source/`;
- the shared licenses, notices, validation information and software bill of
  materials;
- the manifests and notices specific to each distributed binary in
  `release-metadata/arm64/` and `release-metadata/x86_64/`.

Each primary download contains only `LUFScale.app`. After extracting it, move
the complete application to the macOS Applications folder. Do not move or
remove anything from inside `LUFScale.app`.
